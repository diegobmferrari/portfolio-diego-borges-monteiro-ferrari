# 🦠 AmebaMaker

## 📝 Descrição do Projeto
O **AmebaMaker** é uma ferramenta interativa focada em design e manipulação visual, aliada a recursos de Inteligência Artificial. Além do desenvolvimento técnico da aplicação, o repositório serve como um laboratório prático para estudar o impacto das ferramentas generativas na engenharia de software e a aplicação de diretrizes éticas na criação de tecnologia.

O desenvolvimento da solução baseou-se no princípio da "Transformação Significativa + Transparência". Isso garante que a ferramenta apresente mudanças claras e inovadoras nos níveis de estrutura, experiência de usuário ou propósito, documentando adequadamente o uso de IA.

## 🚀 Funcionalidades e Melhorias Implementadas
O sistema recebeu recursos avançados de edição para entregar maior flexibilidade aos usuários na criação de layouts:
* **Gestão de Imagens:** Envio de imagem, podendo alterar tamanho e posição.
* **Visão Computacional (IA):** Remover fundo com recurso I.A.
* **Edição Tipográfica:** Adicionar texto, podendo alterar tamanho cor e posição.
* **Exportação Responsiva:** Adicionado tamanhos e formatos para utilização em diferentes plataformas.

## 🧠 Paradigmas de Desenvolvimento Abordados
O projeto também reflete as novas exigências para o desenvolvimento de software assistido por inteligência artificial:
* **Evolução do Papel Técnico:** O engenheiro júnior deixa de ser um "executor de código" e passa a ser um orquestrador de soluções, alguém que entende o problema, guia a IA e valida o resultado.
* **Novas Competências:** A prática exigiu pensamento lógico e modelagem de problemas, habilidades em engenharia de prompt e comunicação técnica, além de forte pensamento crítico para revisão e validação de inconsistências.
